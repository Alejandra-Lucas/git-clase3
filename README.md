# Ejercicio-git-colaboraciones

## Instrucciones

Considerando lo visto en clase:

- **Haz un fork** de este repositorio desde GitHub.
- **Clona tu fork** en tu computadora.

```
git clone <url>
```

- **Editar** el archivo _participitantes.txt_ agregando tu nombre.
- **Guardar los cambios, crear un commit**
- **Envía los cambios a tu repositorio que forkeaste en GitHub**
